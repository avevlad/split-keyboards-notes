# Keymap

Первый раз делаю что-то для сплита, решил попробовать подумать, пержде чем делать.

Нужно определиться с тем, какие хоткеи я использую при работе с компьютером чаще всего.

- `cmd + alt + ( ← | → )`
  - prev / next tab в браузере / редакторе кода / термиинале
 
- `shift + alt + ( ← | → )`
  - выделяю, чтобы удалить или вырезать, работа с текстом в браузере / редакторе кода
 
- caps lock
  - переключение языка с ру на en, **супер частый** кейс


## Редактор кода (vscode)


- `alt + ( ↑ | ↓ )`
    - smart selection в vsode

- `cmd + shift + ( ↑ | ↓ )`
    - переместить строку / выделенный блок выше / ниже
